# ЦУП Альтаир

**ЦУП Альтаир — Центр управления полётами** — локальное Windows-приложение учебной наземной станции для малых космических аппаратов.

**Текущий релиз: v6 / 0.6.0 — Технопром 2026, «Миссия на Луну».**

## Что нового в v6

Основной радиопакет теперь имеет фиксированную структуру и передаётся как ASCII-строка:

```text
02,00001,00015,3.00,4.20,1,33
```

Поля:

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM
```

- ID — 2 символа;
- номер пакета — 5 цифр;
- uptime — 5 цифр, секунд;
- мощность панелей — `X.XX`;
- напряжение аккумулятора — `X.XX`;
- режим — `1` штатный / `0` аварийный;
- XOR — 2 HEX-символа.

**Фактическая длина такого пакета — 29 символов.** Число 23 не согласуется с указанными длинами полей и шестью разделительными запятыми.

Контрольная сумма примера действительно равна `33`: XOR рассчитывается по строке

```text
02,00001,00015,3.00,4.20,1,
```

то есть последняя запятая включена в расчёт.

## Радиоканал v6

Основной профиль CC1101:

```text
435.000 MHz
4.8 kbps
2-FSK
5 kHz deviation
58 kHz RX bandwidth
5 dBm
16-bit preamble
```

Наземная архитектура:

```text
STM32 + CC1101
      │
      │ 435 MHz
      ▼
CC1101 + ESP32-WROOM-32
      │ USB
      ▼
ЦУП Альтаир
```

ESP32 проверяет XOR и только после успешной проверки передаёт данные в приложение. Дополнительно наземный шлюз добавляет `RSSI`, `LQI` и оценочный `SNR`.

## STM32-передатчик

Готовый статический тестовый скетч:

```text
firmware/transmitter_stm32_v6/Transmit_v6_static/Transmit_v6_static.ino
```

Он основан на ранее работавшем варианте подключения:

```text
CS   = PA2
GDO0 = PA0
GDO2 = PA1
```

Передаёт один и тот же пакет раз в секунду. Для референсной CI-сборки используется профиль `bluepill_f103c8`; если фактическая плата другая, необходимо выбрать соответствующий профиль STM32, сохранив реальные выводы CC1101.

## ESP32-радиошлюз

Проект:

```text
firmware/radio_gateway_esp32/
```

Версия firmware для v6: **0.3.0**. При первом запуске v6 старые сохранённые настройки v5 мигрируются на новый профиль 435.000 МГц.

Штатное подключение CC1101 к ESP32-WROOM-32:

| CC1101 | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCK | GPIO18 |
| MISO | GPIO19 |
| MOSI | GPIO23 |
| CSn | GPIO21 |
| GDO0 | GPIO4 |
| GDO2 | GPIO27 |

## Телеметрия на экране

ЦУП v6 показывает:

- ID спутника;
- номер пакета;
- время работы после запуска;
- мощность солнечных панелей;
- напряжение аккумулятора;
- режим работы;
- контрольную сумму XOR;
- RSSI;
- SNR.

Поле состояния раскрытия антенны, добавленное в v5, сохранено как дополнительное. В минимальный 29-символьный пакет v6 оно не входит.

Графики строятся для напряжения аккумулятора, мощности панелей, RSSI и SNR.

## Аварийный режим

В окончательной бортовой программе:

```cpp
mode = (batteryVoltage < 2.00f) ? 0 : 1;
```

В статическом тестовом пакете напряжение `4.20 В`, поэтому режим равен `1`.

## Установка Windows

Релизный установщик:

```text
CUP-Altair-Setup-0.6.0.exe
```

После установки оператору не требуются Python, PlatformIO или Arduino IDE. Прошивка ESP32 по-прежнему может выполняться прямо из ЦУП Альтаир.

## Что обязательно проверить на стенде

Автоматическая сборка подтверждает компиляцию ПО, но перед демонстрацией нужно физически проверить:

1. STM32 + CC1101 на 435.000 МГц;
2. приём того же пакета ESP32 + CC1101;
3. правильность XOR `33` для тестовой строки;
4. заполнение карточек ЦУПа;
5. реальные значения RSSI/SNR;
6. работу конкретной STM32-платы и её SPI-распиновку.
