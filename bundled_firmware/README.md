# Bundled ESP32 firmware

Эта папка заполняется автоматически при сборке desktop-версии OpenMCC.

GitHub Actions компилирует `firmware/radio_gateway_esp32`, затем копирует в эту папку четыре образа для ESP32-WROOM-32:

- bootloader — `0x1000`;
- partition table — `0x8000`;
- boot_app0 — `0xE000`;
- OpenMCC radio gateway application — `0x10000`.

Также генерируется `manifest.json` с версией прошивки, размерами и MD5 каждого образа. Именно этот комплект включается внутрь Windows-установщика и используется разделом **«Прошивка ESP32»**.

Бинарные файлы намеренно не хранятся вручную в Git: они создаются из исходников в CI, чтобы исключить рассинхронизацию между кодом и установленной прошивкой.
