# ЦУП Альтаир v5 — телеметрия раскрытия антенны

## Назначение

В релизе `0.5.0` в телеметрию аппарата добавлен параметр состояния бортовой рулеточной антенны.

Параметр называется:

```text
ANTENNA
```

Значения:

```text
ANTENNA=1  — антенна раскрыта
ANTENNA=0  — антенна сложена
```

Другие числовые значения считаются ошибкой телеметрии.

## Рекомендуемый пакет для Технопрома 2026

Для текущей миссии рекомендуется формат `KEY=VALUE`, поскольку он позволяет добавлять новые поля без изменения порядка уже существующих параметров:

```text
$TM,ID=04,PACKET=427,UPTIME=1864,VOLT=4.12,PANEL_POWER=1.850,TEMP=24.4,ANTENNA=1
```

После приёма через ESP32 + CC1101 наземный шлюз добавляет параметры качества радиоканала, и в ЦУП поступает строка вида:

```text
$TEL,ID=04,PACKET=427,UPTIME=1864,VOLT=4.12,PANEL_POWER=1.850,TEMP=24.4,ANTENNA=1,RSSI=-76.5,SNR=18.2,LQI=103
```

На экране значение отображается как:

```text
1 · РАСКРЫТА
```

или:

```text
0 · СЛОЖЕНА
```

## Позиционный пакет

Парсер ЦУП Альтаир также понимает расширенный позиционный вариант:

```text
$TM,<ID>,<PACKET>,<UPTIME>,<VOLT>,<PANEL_POWER>,<TEMP>,<ANTENNA>
```

Например:

```text
$TM,04,427,1864,4.12,1.850,24.4,1
```

Для реальной работы через текущий ESP32-шлюз рекомендуется `KEY=VALUE` вариант выше: шлюз передаёт все именованные поля без изменения и автоматически добавляет RSSI/SNR/LQI.

## Передатчик

Пример находится в:

```text
examples/technoprom_2026_transmitter/Transmit_v5.ino
```

В нём функция:

```cpp
uint8_t readAntennaDeployed()
```

пока возвращает демонстрационное значение `1`. Перед использованием на реальном аппарате её следует связать с фактической логикой определения раскрытия — например, с концевым выключателем, датчиком или программным флагом механизма раскрытия.

## Важно

Параметр должен описывать **фактическое состояние**, а не только факт выдачи команды на раскрытие. Если команда была отправлена, но подтверждения от механизма нет, `ANTENNA` не следует автоматически устанавливать в `1`.
