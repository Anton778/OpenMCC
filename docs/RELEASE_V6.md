# ЦУП Альтаир v6 / 0.6.0

Дата подготовки релиза: 26 августа 2026 г.

## Основной пакет телеметрии

Канонический пакет v6:

```text
02,00001,00015,3.00,4.20,1,33
```

Длина пакета — 29 ASCII-символов. Поля имеют фиксированную длину и разделяются запятыми:

```text
ID(2), PACKET(5), UPTIME(5), PANEL_POWER(4), VOLT(4), MODE(1), CHECKSUM(2 HEX)
```

Контрольная сумма XOR рассчитывается по всей строке перед двумя HEX-символами контрольной суммы, включая последнюю запятую. Для канонического примера XOR равен `0x33`.

`MODE=1` означает штатный режим, `MODE=0` — аварийный. В рабочей бортовой логике аварийный режим должен автоматически включаться при напряжении аккумулятора ниже 2.00 В.

```text
Девиация:      5 кГц
RX bandwidth:  58 кГц
TX power:      5 dBm
```

## Передатчик STM32

В каталоге `firmware/transmitter_stm32_v6` находится пример передатчика STM32 + CC1101, который раз в секунду передаёт статический канонический пакет v6 на 435.000 МГц.

## Наземный шлюз ESP32

ESP32-WROOM-32 + CC1101 принимает пакет, проверяет XOR и передаёт в ЦУП нормализованную строку `$TEL` с добавленными наземными параметрами RSSI, LQI и диагностической оценкой SNR.

## Windows-приложение

Версия приложения: `0.6.0`.

Имя установщика:

```text
CUP-Altair-Setup-0.6.0.exe
```

Релиз содержит исходный код ЦУПа, документацию, STM32-передатчик и встроенную прошивку ESP32-радиошлюза.
