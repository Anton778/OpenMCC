# ЦУП Альтаир — техническое руководство пользователя

Версия документа: **v5 / 0.5.0**  
Сценарий: **Технопром 2026 — Миссия на Луну**

Главный документ именно по радиопакету и текущему передатчику: `TECHNOPROM_2026_MOON_MISSION.md`.

---

## 1. Назначение системы

**ЦУП Альтаир — Центр управления полётами** — локальное Windows-приложение учебной наземной станции. Оно объединяет:

- последовательное USB-соединение;
- приём и разбор телеметрии;
- числовое отображение параметров аппарата;
- графики в реальном времени;
- журналирование;
- командный канал;
- настройку CC1101 или E32-433T30D;
- встроенную прошивку ESP32-WROOM-32;
- ручное управление двухосевой повороткой AZ/EL;
- 3D-визуализацию аппарата;
- заготовку под будущую навигацию и автосопровождение.

После установки интернет для штатной работы не требуется.

---

## 2. Установка и запуск

Основной файл релиза:

```text
CUP-Altair-Setup-0.5.0.exe
```

После установки запускайте ярлык **«ЦУП Альтаир»**.

Для обычного пользователя не требуются:

```text
Python
Node.js
Arduino IDE
PlatformIO
отдельный браузер
```

Исходная веб-версия по-прежнему может запускаться через локальный HTTP-сервер, но встроенный прошивальщик ESP32 рассчитан прежде всего на desktop-релиз, где бинарные образы включены в установщик.

---

## 3. Рекомендуемый порядок работы

1. Запустить ЦУП Альтаир.
2. Подключить ESP32-WROOM-32 радиошлюза к USB.
3. При необходимости прошить её через раздел **«Прошивка ESP32»**.
4. В разделе **«Радиоканал ЦУПа»** выбрать установленный модуль.
5. Для текущего стенда CC1101 нажать **«Применить профиль Технопром 2026»**.
6. Подключить основной последовательный порт на `115200 бод`.
7. Включить передатчик аппарата.
8. Убедиться в появлении пакетов/сообщений в журнале.
9. Проверить карточки телеметрии и графики.
10. При необходимости использовать командный канал.
11. Поворотку подключать отдельной кнопкой; до аппаратной калибровки использовать симулятор.

## 4. Главный экран v5

### Соединение

Основной порт используется для ESP32-радиошлюза либо для прямого тестового подключения Arduino/STM32.

Штатная скорость ESP32 gateway:

```text
115200 бод, 8N1
```

### Телеметрия

Отображаются:

| Поле | Смысл |
|---|---|
| `ID` | ID спутника |
| `VOLT` | напряжение аккумулятора |
| `PANEL_POWER` | мощность солнечных панелей |
| `PACKET` | счётчик переданных аппаратом пакетов |
| `UPTIME` | секунды после включения/запуска |
| `TEMP` | температура |
| `RSSI` | уровень принятого сигнала |
| `SNR` | оценка отношения сигнал/шум |

Ток в v5 не используется.

### Графики

Сразу после телеметрии строятся:

```text
VOLT
PANEL_POWER
TEMP
RSSI
SNR
```

Кнопка **«Пауза»** прекращает добавление точек на график, но не останавливает приём телеметрии. **«Очистить»** очищает локальный буфер графиков.

### Команды

Есть быстрые кнопки, готовые примеры и поле произвольной команды. Общий формат:

```text
$CMD,<КОМАНДА>[,PARAM=VALUE]
```

Команды самого gateway (`GATEWAY_INFO`, `RADIO_STATUS`, конфигурация RF) обрабатываются ESP32. Остальные команды пересылаются по радиоканалу и должны поддерживаться бортовой прошивкой.

## 5. Радиоканал CC1101

### Подключение

| CC1101 | ESP32-WROOM-32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCK | GPIO18 |
| MISO | GPIO19 |
| MOSI | GPIO23 |
| CSn | GPIO21 |
| GDO0 | GPIO4 |
| GDO2 | GPIO27 |

### Профиль Технопром 2026

```text
434.000 МГц
4.8 kbps
2-FSK
deviation 5 кГц
RX bandwidth 58 кГц
TX power 5 dBm
CRC ON
CCA ON
```

Профиль выбран по фактическим вызовам загруженного `Transmit.ino`, а не по устаревшим комментариям внутри него.

Команда из интерфейса:

```text
$CMD,RADIO,TYPE=CC1101,FREQ=434.000,POWER=5,RATE=4.8,MOD=2FSK,BW=58,CRC=1,CCA=1
```

## 6. Радиоканал E32-433T30D

Подключение:

| E32 | ESP32-WROOM-32 |
|---|---|
| TXD | GPIO16 / RX2 |
| RXD | GPIO17 / TX2 |
| M0 | GPIO25 |
| M1 | GPIO26 |
| AUX | GPIO27 |
| GND | GND |

Для режима высокой мощности предусмотрите отдельный подходящий источник питания и общую землю.

## 7. Пакет телеметрии

Основной формат v5:

```text
$TM,<ID>,<PACKET>,<UPTIME>,<VOLT>,<PANEL_POWER>,<TEMP>
```

Пример:

```text
$TM,04,427,1864,4.12,1.850,24.4
```

После CC1101 gateway приложение обычно получает:

```text
$TEL,ID=04,PACKET=427,UPTIME=1864,VOLT=4.12,PANEL_POWER=1.850,TEMP=24.4,RSSI=-76.5,SNR=18.2,LQI=103
```

Поддерживаются также `$TEL,KEY=VALUE,...`, JSON и legacy IntroSat пакет.

Если в эфире пришёл произвольный текст без полей телеметрии, он не считается ошибкой и выводится как диагностический `RF_RAW`.

## 8. RSSI и SNR

`RSSI` считывается из CC1101.

`SNR` для CC1101 в v5 — оценочная наземная величина:

```text
SNR_est ≈ RSSI_packet − RSSI_noise_floor
```

Это сделано потому, что CC1101 не предоставляет готовое прямое значение SNR пакета. Используйте показатель для сравнения условий приёма; для метрологических измерений нужна отдельная калибровка.

## 9. Прошивка ESP32 из приложения

Раздел прошивки появляется в desktop-версии после панели радиоканала.

Он использует `esptool-js` и встроенный firmware bundle.

Записываются:

```text
0x1000   bootloader
0x8000   partition table
0xE000   boot_app0
0x10000  radio gateway application
```

После записи выполняется MD5-проверка всех областей и hard reset. Полное стирание Flash по умолчанию не выполняется.

Если auto-reset конкретной платы не срабатывает, используется стандартный ручной вход в загрузчик через `BOOT` и `EN/RESET`.

## 10. Поворотное устройство

Отдельный канал:

```text
ЦУП Альтаир
    │ USB
Arduino Uno
    │
CNC Shield V3
    │
NEMA17 AZ + NEMA17 EL
```

Протокол:

```text
$ROT,SET,AZ=145.0,EL=37.5
$ROT,STOP
$ROT,HOME
$ROT,PARK
$ROT,STATUS
```

До определения реального передаточного отношения и проверки концевиков используйте симулятор.

## 11. 3D-модель

3D-панель представляет условную учебную 2U-конфигурацию CubeSat с раскрытой рулеточной дипольной антенной. Это визуализация, а не точная CAD-модель конкретного спутника.

## 13. Что проверять при неисправности

### Нет последовательного порта

- проверить USB-кабель с линиями данных;
- проверить драйвер USB-UART;
- закрыть Arduino IDE/Serial Monitor и другие программы, занявшие COM-порт;
- переподключить устройство.

### ESP32 прошилась, но gateway не подключается

- выбрать профиль `ESP32` и `115200 бод`;
- нажать reset;
- запросить `GATEWAY_INFO`;
- посмотреть журнал.

### Есть RF_RAW, но нет телеметрии

Радиоканал работает, но передатчик ещё посылает произвольную строку. Перейдите на пакет `$TM,...` или `$TEL,...`.

### Нет приёма CC1101

Проверить прежде всего:

```text
частоту 434.000 МГц
4.8 kbps
2-FSK
5 кГц deviation
58 кГц RX bandwidth
CRC/preamble/sync compatibility
питание 3,3 В
SPI и GDO0
антенну
```

## 14. Ограничения релиза v5

Программная сборка может подтвердить компиляцию и целостность установщика, но не заменяет физические испытания. До демонстрации необходимо проверить реальный CC1101-стенд, конкретную ESP32 и механику поворотки.
