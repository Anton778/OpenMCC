# ЦУП Альтаир

**ЦУП Альтаир — Центр управления полётами**  
**Технопром 2026 · Миссия на Луну**

Текущий стабильный релиз: **v7.1 / 0.7.1**.

> **Важно.** В релизе `0.7.0` ручной Arduino-скетч ESP32 был рабочим, но встроенный в установщик `gateway-firmware.bin` собирался из другого, более сложного исходника. На реальном стенде это привело к отсутствию телеметрии. В `0.7.1` эта ошибка устранена: встроенная прошивка и Arduino-скетч используют один и тот же проверенный алгоритм приёма `radio.receive(packet)` с полосой **203 кГц**.

## Быстрый запуск

1. В STM32 загрузить `Transmit_v7_static.ino`.
2. В ESP32-WROOM-32 загрузить `Altair_Gateway_v7.ino` через Arduino IDE **или** прошить ESP32 встроенной прошивкой из ЦУП Альтаир v7.1. В версии 0.7.1 оба варианта используют один и тот же алгоритм приёма.
3. Подключить ESP32 к компьютеру по USB.
4. Если использовался Arduino Serial Monitor — **закрыть его**, иначе COM-порт будет занят.
5. Запустить `ЦУП Альтаир`, выбрать профиль ESP32, скорость `115200` и подключить COM-порт.
6. Включить STM32-передатчик. Телеметрия должна появиться на главном экране автоматически.

Если требуется проверить шлюз отдельно, откройте Serial Monitor на `115200`. При нормальном приёме должна появляться строка вида:

```text
$TEL,ID=02,PACKET=00001,UPTIME=00015,PANEL_POWER=3.00,VOLT=4.20,MODE=1,CHECKSUM=33,CHECKSUM_OK=1,RSSI=-23.5,SNR=60.0,LQI=52
```

После проверки **закройте Serial Monitor** и только затем подключайте тот же COM-порт в ЦУПе.

## Проверенная радиолиния v7.1

```text
STM32 + CC1101 IntroSat
        |
        | 435.000 MHz
        v
обычный CC1101 + ESP32-WROOM-32
        |
        | USB 115200
        v
ЦУП Альтаир v7.1
```

Рабочий профиль CC1101:

```text
Frequency:      435.000 MHz
Bit rate:       4.8 kbps
Modulation:     2-FSK
Deviation:      5 kHz
RX bandwidth:   203 kHz
Sync word:      0x12AD
Encoding:       NRZ
Packet length:  variable
CRC:            ON
Preamble:       16 bit
TX power:       5 dBm
```

**Почему 203 кГц:** на реальном стенде при 58 кГц пакет не принимался, а при 203 кГц тот же передатчик уверенно декодировался. Поэтому v7.1 использует широкую полосу 203 кГц по умолчанию.

## Пакет телеметрии

Канонический тестовый пакет:

```text
02,00001,00015,3.00,4.20,1,33
```

Длина — **29 ASCII-символов**. Поля:

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM
```

XOR `33` рассчитывается по строке:

```text
02,00001,00015,3.00,4.20,1,
```

Последняя запятая включается в XOR.

## Что выводится на экран

Порядок карточек строго такой:

```text
ID спутника
номер пакета
время работы
мощность солнечных панелей
напряжение аккумулятора
режим работы
контрольная сумма XOR
раскрытие антенны
RSSI
SNR
```

`RSSI` и `SNR` расположены **в самом конце — после раскрытия антенны**.

Поле раскрытия антенны в минимальном 29-символьном пакете пока отсутствует. Поэтому интерфейс показывает **«Н/Д»**, а не прочерк. В будущем: `1 = раскрыта`, `0 = сложена`.

Графики строятся для `VOLT`, `PANEL_POWER`, `RSSI`, `SNR`; **на каждой линии отображаются точки фактических отсчётов**.

## Подключение CC1101 к ESP32

| CC1101 | ESP32-WROOM-32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCK | GPIO18 |
| MISO / SO | GPIO19 |
| MOSI / SI | GPIO23 |
| CSN / CS | GPIO21 |
| GDO0 | GPIO4 |
| GDO2 | GPIO27 |

CC1101 питается от **3.3 В**.

## Передатчик STM32

Основной файл:

`firmware/transmitter_stm32_v7/Transmit_v7_static/Transmit_v7_static.ino`

Сохранённое рабочее подключение IntroSat:

```text
CS   -> PA2
GDO0 -> PA0
GDO2 -> PA1
SPI  -> штатные SPI-выводы STM32
```

Скетч раз в секунду передаёт статический пакет v7 и подходит для первичной проверки всей цепочки.

## ESP32 радиошлюз

Для ручной загрузки через Arduino IDE используйте:

`firmware/radio_gateway_esp32/Altair_Gateway_v7/Altair_Gateway_v7.ino`

Ключевой вызов приёма:

```cpp
const int state = radio.receive(packet);
```

Именно этот вариант с RX BW **203 кГц** был подтверждён на реальном стенде. В `0.7.1` встроенный `gateway-firmware.bin`, прошиваемый из программы ЦУПа, собран из той же логики.
