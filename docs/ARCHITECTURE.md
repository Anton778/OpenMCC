## Целевая система

```text
                               ┌──────────────────────┐
                               │       OpenMCC        │
                               │  browser / localhost │
                               └──────────┬───────────┘
                                          │ USB Web Serial
                             ┌────────────┴────────────┐
                             │                         │
                    ┌────────▼────────┐       ┌────────▼────────┐
                    │ ESP32-WROOM-32  │       │  Arduino Uno #2 │
                    │ Radio Gateway   │       │ Rotator Control │
                    └────────┬────────┘       └────────┬────────┘
                             │                         │
                   ┌─────────┴─────────┐              CNC Shield V3
                   │                   │               │        │
                 SPI                 UART           NEMA17    NEMA17
                   │                   │               AZ        EL
               CC1101          E32-433T30D
                   └─────────┬─────────┘
                             │ RF
                         ┌───▼───┐
                         │  МКА  │
                         └───────┘
```

## Принцип независимости радиомодуля

OpenMCC должен видеть не CC1101/E32 напрямую, а логический шлюз ESP32. Поэтому браузер отправляет одинаковые команды независимо от выбранного радиомодуля.

```text
OpenMCC command
      │
      ▼
ESP32 gateway protocol
      │
      ├── driver_cc1101
      └── driver_e32
```

Это позволяет менять физический модуль без переделки интерфейса.
