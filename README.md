# OpenMCC

**OpenMCC (Open Mission Control Center)** — локальный веб-интерфейс учебного центра управления полётами для CubeSat/МКА. Проект работает офлайн, использует Web Serial API для связи с микроконтроллерами и постепенно расширяется до полноценной наземной станции с радиоканалом и автоматическим сопровождением спутника.

## Что уже работает

- подключение Arduino/STM32/ESP32 через Web Serial;
- приём и разбор телеметрии;
- отправка команд;
- журнал событий;
- графики в реальном времени на Chart.js;
- 3D-модель CubeSat на Three.js;
- отдельный интерфейс двухосевой поворотки AZ/EL;
- симулятор поворотного устройства без реальной механики;
- демонстрационная прошивка Arduino Uno/Nano для телеметрии.

## Что пока не реализовано

- реальный радиошлюз на ESP32-WROOM-32;
- драйвер CC1101;
- драйвер E32-433T30D;
- единый пакетный протокол радиоканала с CRC/подтверждениями;
- TLE/SGP4;
- карта орбиты и радиогоризонт;
- автоматическое сопровождение спутника;
- проверка реальной механики SatNOGS Rotator v3.

## Быстрый запуск

### Windows

Запустите:

```text
start_openmcc.bat
```

### Вручную

Из корневой папки проекта:

```bash
py -m http.server 8000
```

Затем откройте в Chrome или Edge:

```text
http://localhost:8000/
```

> OpenMCC нельзя полноценно запускать как `file:///.../index.html`, потому что Web Serial и ES-модули требуют корректного контекста. `localhost` работает без доступа в интернет.

## Тест телеметрии

Демонстратор:

```text
examples/arduino_avr_demo/OpenMCC_Arduino_AVR/OpenMCC_Arduino_AVR.ino
```

Загрузите его в Arduino Uno/Nano, подключите плату к ПК, выберите в OpenMCC `Arduino Uno` и `115200 бод`, затем нажмите **«Подключить устройство»**.

## Архитектура

```text
                         OpenMCC
                            │
          ┌─────────────────┴─────────────────┐
          │                                   │
      USB / Serial                       USB / Serial
          │                                   │
 ESP32-WROOM-32                        Arduino Uno №2
 радиошлюз ЦУПа                         SatNOGS Rotator v3
          │                                   │
   CC1101 или E32                         CNC Shield V3
          │                                   │
       радиоканал                        NEMA17 AZ / EL
          │
         МКА
```

Пока радиошлюз не реализован, основное USB-соединение можно использовать напрямую с демонстрационной Arduino.

## Важный принцип проекта

OpenMCC должен оставаться независимым от конкретного радиомодуля. CC1101 и E32-433T30D будут скрыты за ESP32-WROOM-32, а браузерный интерфейс продолжит работать с единым протоколом телеметрии и команд.
