## Следующий разумный этап

**ESP32-WROOM-32 → радиошлюз OpenMCC.**

После закупки радиомодуля реализовать один из драйверов:

```text
CC1101        → SPI
E32-433T30D   → UART
```

Внешний протокол OpenMCC при этом оставить одинаковым.
