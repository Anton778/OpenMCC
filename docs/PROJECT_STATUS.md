# ЦУП Альтаир — статус проекта

Релиз: **v5 / 0.5.0**  
Сценарий: **Технопром 2026 — Миссия на Луну**

## Готово программно

| Узел | Статус | Примечание |
|---|---|---|
| Windows desktop-приложение | ✅ Готово | Electron, локальная работа без Python |
| Новый интерфейс «ЦУП Альтаир» | ✅ Готово | Технопром 2026 / Миссия на Луну |
| Основной USB Serial | ✅ Готово | ESP32 / Arduino / STM32 |
| Телеметрия v5 | ✅ Готово | `ID`, `VOLT`, `PANEL_POWER`, `PACKET`, `UPTIME`, `ANTENNA`, `TEMP`, `RSSI`, `SNR` |
| Состояние раскрытия антенны | ✅ Готово в ПО | `1` — раскрыта, `0` — сложена; отдельная карточка в телеметрии |
| Измерение тока | ✅ Удалено | Не используется в v5 |
| Парсер `$TM` | ✅ Готово | KEY=VALUE + позиционный пакет + legacy IntroSat |
| Парсер `$TEL` | ✅ Готово | `KEY=VALUE` |
| Графики | ✅ Готово | VOLT / PANEL_POWER / TEMP / RSSI / SNR |
| Журнал | ✅ Готово | ACK / ERR / INFO / RF_RAW |
| Командный канал | ✅ Готово | `$CMD,...` + готовые примеры |
| RF UI | ✅ Готово | CC1101 / E32, схемы подключения, настройка параметров |
| Профиль CC1101 Технопром 2026 | ✅ Готово | 434.000 МГц / 4.8 kbps / 2-FSK / 5 кГц / 58 кГц |
| ESP32 radio gateway | ✅ Готово программно | firmware v0.2.0 |
| Встроенная прошивка ESP32 | ✅ Готово программно | esptool-js, MD5 verify, hard reset |
| Поворотка — интерфейс | ✅ Готово | AZ/EL / STOP / HOME / PARK / STATUS |
| Поворотка — симулятор | ✅ Готово | Без механики |
| Arduino Uno rotator firmware | ✅ Компилируется | Требует калибровки механики |
| 3D CubeSat | ✅ Готово | Условная 2U-модель с дипольной рулеточной антенной |

## Требует аппаратной проверки

| Узел | Статус | Что проверить |
|---|---|---|
| CC1101 ↔ CC1101 | 🟡 Стенд | реальный приём пакета на 434.000 МГц |
| RSSI | 🟡 Стенд | реальные значения и повторяемость |
| SNR_est | 🟡 Стенд | оценка шумового фона и калибровка |
| ESP32-WROOM-32 flasher | 🟡 Стенд | auto-reset/BOOT конкретной платы |
| E32-433T30D | 🟡 Стенд | питание, UART, AUX, RX/TX |
| Бортовые датчики | 🟡 Не подключены | аккумулятор, панель, температура |
| Датчик/логика раскрытия антенны | 🟡 Бортовая часть | фактическое формирование `ANTENNA=0/1` |
| Поворотка | 🟡 Механика | шагов/градус, направления, концевики |
| Команды аппарату | 🟡 Бортовая часть | реализовать обработчики на МКА |
