# ЦУП Альтаир v7.1 / 0.7.1

## Главное исправление

Версия `0.7.1` исправляет ошибку релиза `0.7.0`, из-за которой телеметрия могла не приниматься после прошивки ESP32 встроенной прошивкой из программы.

Причина была найдена после проверки на реальном стенде. Ручной Arduino-скетч `Altair_Gateway_v7.ino` использовал проверенный вызов:

```cpp
const int state = radio.receive(packet);
```

и уверенно принимал пакет при полосе **203 кГц**. Однако `gateway-firmware.bin`, встроенный в установщик `0.7.0`, собирался из другого исходника `main_v7.cpp`, в котором использовалась более сложная обёртка старого шлюза и вызов `receive(..., timeout=250 ms)`. Таким образом, ручная и встроенная прошивки релиза фактически были разными.

В `0.7.1` это устранено: Arduino-скетч и PlatformIO-исходник встроенной прошивки синхронизированы и используют один и тот же проверенный тракт приёма. В CI добавлена отдельная проверка, которая не даст выпустить релиз, если эти два исходника снова разойдутся.

## Рабочий профиль CC1101

- частота: **435.000 МГц**;
- скорость: **4.8 kbps**;
- модуляция: **2-FSK**;
- девиация: **5 кГц**;
- RX bandwidth: **203 кГц**;
- sync word: **0x12AD**;
- encoding: **NRZ**;
- packet length: **variable**;
- CRC: **включён**;
- преамбула: **16 бит**;
- мощность: **5 dBm**.

Полоса 203 кГц зафиксирована как штатная, поскольку именно с ней на стенде был успешно принят пакет STM32 + CC1101 IntroSat обычным CC1101 на ESP32.

## Телеметрия

Канонический пакет:

```text
02,00001,00015,3.00,4.20,1,33
```

Порядок карточек на экране:

`ID -> PACKET -> UPTIME -> PANEL_POWER -> VOLT -> MODE -> CHECKSUM -> ANTENNA -> RSSI -> SNR`

RSSI и SNR находятся в самом конце, после состояния раскрытия антенны. В минимальном 29-символьном пакете поля антенны пока нет, поэтому интерфейс показывает `Н/Д`, а не прочерк.

## Быстрая проверка

После прошивки ESP32 открыть Serial Monitor на `115200`. При включённом STM32 должны появляться строки `$TEL,...`. После проверки Serial Monitor необходимо закрыть, затем открыть ЦУП Альтаир и подключить тот же COM-порт.
