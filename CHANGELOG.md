# Changelog

## v0.7.0 / v7 — рабочий стендовый радиоканал · RX BW 203 кГц

- штатная полоса приёмника CC1101 расширена с 58 до **203 кГц**: именно с этой полосой реальный стенд STM32 + CC1101 IntroSat → ESP32 + обычный CC1101 начал устойчиво декодировать пакет;
- рабочий профиль зафиксирован как 435.000 МГц / 4.8 kbps / 2-FSK / deviation 5 кГц / RX BW 203 кГц / sync 0x12AD / NRZ / variable packet length / CRC ON;
- добавлен новый интегрированный ESP32 gateway v7 и отдельный простой Arduino IDE скетч `Altair_Gateway_v7.ino` на основе фактически заработавшего приёмника;
- добавлен STM32-передатчик `Transmit_v7_static.ino` с тем же пакетным профилем и статическим пакетом `02,00001,00015,3.00,4.20,1,33`;
- порядок карточек телеметрии приведён к `ID → PACKET → UPTIME → PANEL_POWER → VOLT → MODE → CHECKSUM → ANTENNA → RSSI → SNR`;
- RSSI и SNR теперь всегда находятся в самом конце, после карточки раскрытия антенны;
- при отсутствии поля антенны в минимальном 29-символьном пакете отображается **«Н/Д»** вместо прочерка;
- на графиках VOLT / PANEL_POWER / RSSI / SNR добавлены видимые точки каждого принятого отсчёта;
- главная страница README переписана как практический быстрый старт с прямыми ссылками на установщик, скетчи и руководство;
- добавлены `docs/CUP_Altair_v7_Manual.tex` и PDF-руководство, которое автоматически собирается и прикладывается к GitHub Release;
- Windows installer повышен до `CUP-Altair-Setup-0.7.0.exe`;
- GitHub Release v0.7.0 публикует установщик, ESP32/STM32 скетчи, PDF/TeX руководство, ESP32 firmware и manifest.

## v0.6.0 / v6 — фиксированный пакет телеметрии · 435 МГц

- основной формат телеметрии заменён на фиксированную ASCII-строку `02,00001,00015,3.00,4.20,1,33`;
- фактическая длина пакета зафиксирована как **29 символов**; число 23 не соответствует сумме длин полей и запятых;
- порядок полей: `ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM`;
- `ID` — 2 символа, `PACKET` и `UPTIME` — по 5 цифр, вещественные поля — `X.XX`, `MODE` — 1 символ, XOR — 2 HEX;
- реализована проверка XOR по ASCII-символам с включением последней разделительной запятой;
- для канонического примера подтверждён XOR `0x33`;
- `MODE=1` отображается как штатный режим, `MODE=0` — аварийный;
- в документации зафиксировано правило бортовой логики: при `VOLT < 2.00 В` режим должен автоматически переходить в `0`;
- основной профиль CC1101 перенесён на **435.000 МГц** при 4.8 kbps, 2-FSK, девиации 5 кГц, RX BW 58 кГц и мощности 5 dBm;
- ESP32 radio gateway обновлён до **0.3.0**, принимает 29-символьный пакет, проверяет XOR и выдаёт нормализованный `$TEL` с RSSI/LQI/SNR;
- добавлена миграция сохранённого профиля v5, чтобы после обновления старое значение 434 МГц не осталось в NVS;
- добавлен STM32-скетч `firmware/transmitter_stm32_v6/Transmit_v6_static/Transmit_v6_static.ino` на основе ранее работавших выводов `PA2/PA0/PA1`;
- STM32-скетч передаёт одну и ту же тестовую строку раз в секунду на 435.000 МГц;
- добавлена референсная PlatformIO-сборка `bluepill_f103c8` для проверки скетча;
- интерфейс ЦУПа перестроен под поля v6: ID, пакет, uptime, панель, аккумулятор, режим, XOR, RSSI, SNR;
- температура убрана из основного набора v6, графики оставлены для VOLT / PANEL_POWER / RSSI / SNR;
- состояние раскрытия антенны из v5 сохранено как дополнительное поле, но не включено в минимальный пакет v6;
- добавлен документ `docs/TELEMETRY_V6.md`;
- Windows installer повышен до `CUP-Altair-Setup-0.6.0.exe`;
- CI теперь отдельно проверяет XOR примера, сборку ESP32 gateway и референсную сборку STM32-передатчика.

## v0.5.0 / v5 — ЦУП Альтаир · Технопром 2026 · Миссия на Луну

- приложение переименовано в **«ЦУП Альтаир»**, подзаголовок — «Центр управления полётами»;
- добавлено оформление **«Технопром 2026 — Миссия на Луну»**;
- главный экран перестроен: сразу после телеметрии расположены графики, затем команды, радиоканал, прошивка ESP32 и поворотное устройство;
- состав телеметрии изменён на `ID`, `VOLT`, `PANEL_POWER`, `PACKET`, `UPTIME`, `ANTENNA`, `TEMP`, `RSSI`, `SNR`;
- добавлено состояние раскрытия рулеточной антенны: `ANTENNA=1` — раскрыта, `ANTENNA=0` — сложена;
- карточка раскрытия антенны визуально меняет состояние и выводит `1 · РАСКРЫТА` либо `0 · СЛОЖЕНА`;
- параметр тока `CURR` полностью удалён из интерфейса v5 и графиков;
- рекомендуется именованный пакет `$TM,ID=...,PACKET=...,UPTIME=...,VOLT=...,PANEL_POWER=...,TEMP=...,ANTENNA=...`;
- парсер также принимает позиционный пакет `$TM,<ID>,<PACKET>,<UPTIME>,<VOLT>,<PANEL_POWER>,<TEMP>,<ANTENNA>`;
- сохранена поддержка `$TEL,KEY=VALUE,...` и legacy IntroSat `$TM`;
- графики v5: аккумулятор, мощность солнечных панелей, температура, RSSI, SNR;
- проанализирован загруженный `Transmit.ino`: фактические настройки — 434.000 МГц и 5 dBm;
- добавлен профиль CC1101 **«Технопром 2026»**: 434.000 МГц / 4.8 kbps / 2-FSK / 5 кГц deviation / 58 кГц RX BW;
- исходный загруженный скетч сохранён как `examples/technoprom_2026_transmitter/Transmit_original.ino`;
- `Transmit_v5.ino` обновлён: формирует именованный пакет телеметрии и передаёт `ANTENNA=0/1`;
- ESP32 radio gateway обновлён до **0.2.0**;
- CC1101 gateway передаёт именованные `$TM`-поля без потерь и добавляет RSSI/LQI/SNR;
- для свободной тестовой строки исходного передатчика реализован вывод `RF_RAW` в журнал;
- SNR для CC1101 реализован как диагностическая оценка `RSSI_packet - RSSI_noise_floor`, поскольку прямого готового SNR у CC1101 нет;
- добавлен новый mission guide `docs/TECHNOPROM_2026_MOON_MISSION.md`;
- добавлена документация `docs/ANTENNA_TELEMETRY_V5.md`;
- desktop product name и ярлык изменены на **«ЦУП Альтаир»**;
- установщик переименован в `CUP-Altair-Setup-0.5.0.exe`;
- Windows release workflow обновлён для автоматической публикации релиза v0.5.0.

## v0.4.0 — Integrated ESP32 firmware flasher

- добавлен встроенный раздел **«Прошивка ESP32»** в desktop-приложение OpenMCC;
- добавлен официальный `esptool-js 0.6.1` как production dependency;
- прошивка `ESP32-WROOM-32` выполняется прямо из OpenMCC без Arduino IDE, PlatformIO и Python на компьютере оператора;
- перед записью определяется тип чипа; комплект радиошлюза разрешено записывать только в классический ESP32;
- основной Serial-канал OpenMCC автоматически освобождается перед прошивкой;
- добавлены прогресс, диагностический журнал и подсказки по ручному входу в BOOT mode;
- после записи выполняется MD5-проверка каждой области Flash;
- полный `erase-all` по умолчанию не выполняется, NVS не стирается целиком;
- после успешной прошивки можно одной кнопкой подключить ESP32 как радиошлюз и запросить `GATEWAY_INFO` / `RADIO_STATUS`;
- Windows workflow теперь компилирует ESP32 radio gateway перед сборкой установщика и включает bootloader, partitions, boot_app0 и application внутрь `.exe`;
- добавлена документация `docs/FIRMWARE_FLASHER.md`;
- версия Windows-приложения повышена до 0.4.0.

## Radio gateway firmware v0.1.0

- добавлен отдельный PlatformIO-проект `firmware/radio_gateway_esp32` для ESP32-WROOM-32;
- одна прошивка поддерживает альтернативные радиомодули CC1101 и E32-433T30D;
- реализовано применение команд `$CMD,RADIO,...` из существующего RF-интерфейса OpenMCC;
- реализован `RADIO_STATUS`, `GATEWAY_INFO`, `GATEWAY_PING` и `RADIO_OFF`;
- остальные `$CMD,...` автоматически пересылаются в эфир как команды МКА;
- входящие `$TEL/$ACK/$ERR/$INFO` передаются из радиоканала в OpenMCC без изменения;
- для CC1101 реализованы настройка RF, CRC, CCA, RX/TX и выдача RSSI/LQI;
- для E32 реализована запись конфигурации через UART/M0/M1/AUX и прозрачная передача;
- последняя RF-конфигурация сохраняется в NVS ESP32;
- добавлена отдельная GitHub Actions сборка прошивки и готовых `.bin`;
- CI-компиляция прошивки успешно пройдена; физические испытания радиомодулей ещё не выполнены.
