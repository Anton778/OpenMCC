# ЦУП Альтаир v6.1 — исправление приёма CC1101

Версия приложения: **0.6.1**. Это исправленный релиз поколения v6 для Технопрома 2026.

## Что исправлено

На стендовой проверке простой приёмник ESP32 + обычный CC1101 успешно принял пакет от STM32 + CC1101 IntroSat:

```text
02,00001,00015,3.00,4.20,1,33
```

Параметры рабочей радиолинии:

```text
435.000 МГц
4.8 kbps
2-FSK
девиация 5 кГц
RX bandwidth 58 кГц
preamble 16 bit
NRZ
sync word 0x12AD
variable packet length
CRC включён
```

Проблема релиза 0.6.0 находилась в сложной логике приёмного шлюза ESP32. Для v6.1 путь приёма приведён к проверенному стендом варианту: окончание пакета определяется прямым опросом GDO0 (GPIO4) вместо зависимости от callback/interrupt. USB-интерфейс при этом остаётся неблокирующим.

Все пакетные параметры, влияющие на совместимость, задаются явно: NRZ, `0x12AD`, переменная длина пакета и CRC.

## Подключение CC1101 к ESP32-WROOM-32

| CC1101 | ESP32 |
|---|---|
| VCC | 3.3 V |
| GND | GND |
| SCK | GPIO18 |
| MISO / SO | GPIO19 |
| MOSI / SI | GPIO23 |
| CSn | GPIO21 |
| GDO0 | GPIO4 |
| GDO2 | GPIO27 |

## Телеметрия v6

Пакет содержит 29 ASCII-символов:

```text
02,00001,00015,3.00,4.20,1,33
```

Поля:

```text
ID(2),PACKET(5),UPTIME(5),PANEL_POWER(4),VOLT(4),MODE(1),CHECKSUM(2 HEX)
```

XOR вычисляется по строке до контрольной суммы, включая последнюю запятую:

```text
02,00001,00015,3.00,4.20,1,
```

Для приведённого пакета XOR равен `0x33`.
