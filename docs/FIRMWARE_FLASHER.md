# Встроенная прошивка ESP32 из OpenMCC

Начиная с desktop-версии OpenMCC v0.4 оператор может записывать прошивку наземного радиошлюза в `ESP32-WROOM-32` непосредственно из программы. Arduino IDE, PlatformIO и Python на компьютере оператора для этой операции не требуются.

## Что находится внутри установщика

При сборке Windows-приложения GitHub Actions компилирует проект:

```text
firmware/radio_gateway_esp32/
```

и включает в установщик четыре бинарных образа:

| Образ | Адрес Flash | Назначение |
|---|---:|---|
| bootloader.bin | `0x1000` | загрузчик ESP32 |
| partitions.bin | `0x8000` | таблица разделов |
| boot_app0.bin | `0xE000` | служебный загрузчик OTA-раздела |
| firmware.bin | `0x10000` | OpenMCC Radio Gateway |

Полное стирание Flash по умолчанию не выполняется. Это позволяет не уничтожать NVS-раздел целиком и сохранять настройки радиошлюза при обычном обновлении прошивки.

Для каждого образа при сборке вычисляется MD5. После записи OpenMCC запрашивает MD5 соответствующей области Flash у ESP32 и сравнивает его с эталонным значением из встроенного `manifest.json`.

## Как прошить плату

1. Установить и запустить desktop-версию OpenMCC v0.4 или новее.
2. Подключить `ESP32-WROOM-32` к компьютеру USB-кабелем с линиями данных.
3. Открыть раздел **«Прошивка ESP32»**.
4. Оставить рекомендуемую скорость `460800 бод`. Если адаптер работает нестабильно, выбрать `115200 бод`.
5. Нажать **«Прошить радиошлюз»**.
6. В системном окне OpenMCC выбрать нужный последовательный порт ESP32.
7. Не отключать USB до появления состояния **«ГОТОВО»** и прогресса `100 %`.
8. Нажать **«Подключить как шлюз»**. OpenMCC установит профиль ESP32, скорость 115200 бод и отправит `GATEWAY_INFO` и `RADIO_STATUS`.

## Если ESP32 не входит в загрузчик автоматически

Большинство DevKit-плат управляют `BOOT` и `EN` через DTR/RTS и входят в ROM bootloader автоматически. Если конкретная плата или USB-UART преобразователь этого не делает:

1. удерживать кнопку `BOOT`;
2. кратко нажать `EN` / `RESET`;
3. отпустить `EN`;
4. отпустить `BOOT`;
5. повторить прошивку.

## Защита от ошибочной прошивки

OpenMCC после подключения запускает штатное определение чипа через Espressif esptool-js. Комплект радиошлюза разрешено записывать только если обнаружен классический `ESP32`. Если выбрана ESP32-S2, ESP32-S3, ESP32-C3 или другая микросхема, операция прекращается до записи данных.

Если основной последовательный канал OpenMCC уже подключён к ESP32, прошивальщик сначала корректно закрывает это соединение и только затем получает доступ к выбранному порту.

## Используемая технология

Встроенный прошивальщик использует официальный проект Espressif `esptool-js` и Web Serial API. В OpenMCC библиотека устанавливается как production dependency и работает локально, поэтому доступ в интернет во время прошивки не нужен.

Версия, закреплённая для OpenMCC v0.4:

```text
esptool-js 0.6.1
```

## Что не делает встроенный прошивальщик

- не выполняет `erase-all` автоматически;
- не меняет eFuse;
- не выполняет Secure Boot / Flash Encryption provisioning;
- не предназначен для прошивки произвольных плат ESP32 другими образами;
- не заменяет инженерный стенд при разработке самой прошивки.

Назначение этого раздела — безопасно устанавливать известную версию **OpenMCC Radio Gateway** на штатную `ESP32-WROOM-32` наземной станции.
