# STM32 + CC1101 — статический передатчик ЦУП Альтаир v6

Основной скетч:

```text
Transmit_v6_static/Transmit_v6_static.ino
```

Он повторяет схему подключения из ранее использованного `Transmit_original.ino`:

| CC1101 | STM32 |
|---|---|
| CSn | PA2 |
| GDO0 | PA0 |
| GDO2 | PA1 |
| SPI | штатные SPI-выводы платы |
| VCC | 3,3 В |
| GND | GND |

Радиопрофиль v6:

```text
435.000 MHz
4.8 kbps
2-FSK
5 kHz deviation
58 kHz RX bandwidth
5 dBm
16-bit preamble
```

Передаётся одна и та же строка один раз в секунду:

```text
02,00001,00015,3.00,4.20,1,33
```

Длина строки — **29 ASCII-символов**. Указанные в постановке 23 символа не совпадают с арифметикой полей: 2+1+5+1+5+1+4+1+4+1+1+1+2 = 29.

XOR рассчитан по строке:

```text
02,00001,00015,3.00,4.20,1,
```

Последняя запятая входит в расчёт. Результат XOR: `0x33`, поэтому передаваемая строка заканчивается `,33`.

## Сборка

Скетч рассчитан на Arduino Core for STM32, поскольку исходный рабочий код пользователя также использовал Arduino-совместимый API и RadioLib.

В качестве автоматической проверки в репозитории добавлен PlatformIO-профиль `bluepill_f103c8`. Это **референсная сборка**, а не утверждение, что конкретный бортовой STM32 обязательно является Blue Pill. Для другой STM32-платы следует выбрать соответствующую board-конфигурацию, сохранив реальные выводы подключения CC1101.

## Аварийный режим

В статическом тестовом пакете напряжение равно `4.20 В`, поэтому `MODE=1`.

В окончательной бортовой программе режим должен вычисляться автоматически:

```cpp
mode = (batteryVoltage < 2.00f) ? 0 : 1;
```

То есть `0` — аварийный, `1` — штатный.
