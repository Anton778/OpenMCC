# ЦУП Альтаир v8 / 0.8.1

Версия 0.8.1 — доработанный распространяемый релиз после Технопрома-2026. В нём сохранён проверенный радиотракт v8 и существенно улучшена логика рабочего интерфейса.

## Главное

- официальная прошивка ESP32 соответствует реально рабочему стендовому варианту;
- прикладная XOR-проверка отключена: изменение ID/полей больше не отправляет пакет в ошибки;
- рабочая частота **435.000 МГц** постоянно видна на главном экране;
- RX bandwidth наземного CC1101: **203 кГц**;
- проверенный радиопрофиль наземного шлюза зафиксирован;
- логотип Альтаира в шапке отображается без белой подложки;
- версия, кнопка «О программе» и справка находятся в той же строке шапки, без лишней высоты;
- добавлен двухшаговый сценарий **1. Прошивка шлюза → 2. Соединение с ЦУПом**;
- подключение блокируется, пока пользователь не прошьёт ESP32 или явно не подтвердит, что шлюз v8 уже прошит;
- после успешной прошивки и подключения соответствующие панели автоматически сворачиваются;
- блок телеметрии расположен во всю ширину сразу под подключением;
- графики идут непосредственно за телеметрией;
- рядом с графиками добавлен список ожидаемых/принятых ID спутников с теми же цветами, что и линии графиков;
- для каждого ID показываются число принятых пакетов, время последнего пакета и отметка `CMD`, если на него уже передавалась команда;
- сырой COM-терминал перенесён вниз и по умолчанию свёрнут;
- добавлена кнопка полного сброса принятых данных;
- графики разделяются по ID спутников: каждый ID имеет собственную линию, цвет и точки отсчётов;
- добавлена реальная передача RF-команд из ЦУПа через ESP32 + CC1101;
- добавлены служебные `GATEWAY_INFO` и `RADIO_STATUS`;
- добавлено окно «О программе»;
- README содержит фотографии реального ЦУПа и CubeSat;
- после успешной публикации текущего v8 старые GitHub Releases и их теги удаляются, чтобы осталась одна актуальная версия.

## ESP32 gateway

`Altair_Gateway_v8.ino`

Профиль:

```text
435.000 MHz
4.8 kbps
2-FSK
deviation 5 kHz
RX BW 203 kHz
sync 0x12AD
NRZ
variable packet
CC1101 CRC ON
application XOR validation OFF
USB 115200
RF TX ON
```

Базовый пакет:

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM
```

Расширенный пакет:

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,ANTENNA,CHECKSUM
```

Поле `CHECKSUM` в v8 сохраняется для совместимости и отображения, но не проверяется. Аппаратный CRC CC1101 остаётся включённым.

## Командный канал

USB:

```text
$CMD,RF,TO=02,NAME=PING
```

В эфир:

```text
$CMD,TO=02,NAME=PING
```

Поддерживаемые команды интерфейса: `PING`, `INFO`, `TM_START`, `TM_STOP`, `TM_PERIOD`, `USER`.

Служебные команды шлюза:

```text
$CMD,GATEWAY_PING
$CMD,GATEWAY_INFO
$CMD,RADIO_STATUS
```

`RADIO_STATUS` возвращает фиксированный рабочий профиль v8. Старые команды изменения радиопараметров не применяются и получают ответ `RADIO_CONFIG_FIXED`.
