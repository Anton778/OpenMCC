# Передатчик Технопром 2026

В этой папке находятся два варианта скетча передатчика.

## `Transmit_original.ino`

Точная копия файла, загруженного при подготовке ЦУП Альтаир v5. Он нужен как исходная точка совместимости. В текущем виде скетч передаёт тестовую текстовую строку, а не полноценный пакет телеметрии.

Фактические настройки из выполняемого кода:

```text
CC1101
434.000 МГц
5 dBm
```

При `radio.begin(434.00f)` RadioLib использует стартовый CC1101-профиль примерно 4.8 kbps / 5 kHz deviation / 58 kHz RX bandwidth / 2-FSK.

## `Transmit_v5.ino`

Рабочий шаблон пакета для **ЦУП Альтаир v5 / Технопром 2026 — Миссия на Луну**.

Рекомендуемый формат:

```text
$TM,ID=04,PACKET=427,UPTIME=1864,VOLT=4.12,PANEL_POWER=1.850,TEMP=24.4,ANTENNA=1
```

Поля:

- `ID` — идентификатор аппарата;
- `PACKET` — счётчик успешно отправленных пакетов;
- `UPTIME` — время работы после включения, с;
- `VOLT` — напряжение аккумулятора, В;
- `PANEL_POWER` — мощность солнечных панелей, Вт;
- `TEMP` — температура, °C;
- `ANTENNA` — состояние рулеточной антенны: `1` — раскрыта, `0` — сложена.

Функции `readBatteryVoltage()`, `readPanelPower()`, `readTemperature()` и `readAntennaDeployed()` пока содержат демонстрационные значения. Их необходимо связать с реальным оборудованием аппарата.

Для `ANTENNA` рекомендуется передавать именно **подтверждённое фактическое состояние** механизма раскрытия, а не просто факт отправки команды на раскрытие.
