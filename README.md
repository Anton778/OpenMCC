# ЦУП Альтаир

<p align="center">

**ЦУП Альтаир** — учебный центр управления полётами для CubeSat-проектов: приём телеметрии, графики нескольких аппаратов, RAW COM-диагностика, радиопередача команд и работа с поворотным устройством.

**Текущая версия: v8 / 0.8.1.**  
Проект создан в рамках образовательного проекта **«Миссия на Луну»** и профильной смены по спутникостроению; стенд использовался на Технопроме-2026.

## Быстрый запуск

В интерфейсе v8.0.1 запуск специально сделан последовательным:

1. **Прошивка шлюза ЦУП.** Подключите ESP32 и нажмите «Прошить радиошлюз». Если на плате уже находится актуальный Altair Gateway v8, явно нажмите «Шлюз уже прошит v8 — перейти к подключению».
2. **Соединение с ЦУПом.** После шага 1 становится доступно подключение ESP32 на `115200 бод`.
3. Включите спутники-передатчики. Телеметрия появляется сразу под блоком подключения.
4. На графиках каждый `ID` получает собственный цвет и линию. Справа отображается список ожидаемых ID, число принятых пакетов и время последнего выхода на связь.
5. RAW COM находится внизу страницы и нужен только для диагностики; по умолчанию он свёрнут.

После успешной прошивки и соединения служебные панели автоматически сворачиваются, освобождая экран под телеметрию и графики.

## Радиопрофиль

| Параметр | Значение |
|---|---:|
| Частота | **435.000 МГц** |
| Модуляция | 2-FSK |
| Скорость в эфире | 4.8 kbps |
| Девиация | 5 кГц |
| Полоса RX | **203 кГц** |
| Sync word | `0x12AD` |
| Encoding | NRZ |
| Длина пакета | variable |
| CRC CC1101 | включён |
| USB | 115200 бод |

Широкая полоса **203 кГц** выбрана намеренно: на учебных модулях наблюдался заметный частотный уход относительно 435.000 МГц. Профиль наземного CC1101 в v8 зафиксирован.

## Подключение CC1101 к ESP32

| CC1101 | ESP32-WROOM-32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCK | GPIO18 |
| MISO / SO | GPIO19 |
| MOSI / SI | GPIO23 |
| CSN / CS | GPIO21 |
| GDO0 | GPIO4 |
| GDO2 | GPIO27 |

**CC1101 питается только от 3.3 В.**

## Телеметрия

Базовый пакет:

```text
02,00001,00015,3.00,4.20,1,33
```

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM
```

Расширенный вариант с состоянием антенны:

```text
02,00001,00015,3.00,4.20,1,1,33
```

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,ANTENNA,CHECKSUM
```

`ANTENNA=1` — раскрыта, `ANTENNA=0` — сложена. Если поля нет, интерфейс показывает **Н/Д**.

### Контрольная сумма

В v8 **прикладная XOR-проверка отключена**. Поле `CHECKSUM` сохраняется и отображается, но не является причиной отбрасывания пакета. Поэтому изменение ID не требует пересчёта последних двух HEX-символов.

Аппаратный **CRC CC1101 остаётся включённым**.

## Несколько спутников одновременно

ЦУП группирует данные по `ID`. Каждый ID получает отдельную линию и постоянный цвет в рамках текущей сессии. В панели рядом с графиками можно задать ожидаемые ID, например:

```text
01,02,03,04,05,06,07,08,09,10
```

Для каждого аппарата показываются:
- был ли принят хотя бы один пакет;
- цвет линии графика;
- число пакетов;
- время последнего приёма;
- отметка `CMD`, если на этот ID уже отправлялась команда с ЦУПа.

## Передача команд

ESP32-шлюз v8 работает как приёмопередатчик.

ЦУП отправляет шлюзу:

```text
$CMD,RF,TO=02,NAME=PING
```

а ESP32 передаёт в эфир:

```text
$CMD,TO=02,NAME=PING
```

Поддерживаются `PING`, `INFO`, `TM_START`, `TM_STOP`, `TM_PERIOD` и произвольная `USER`-команда. Реакцию на команды реализует бортовая прошивка спутника.

## Если телеметрия не появляется

1. Убедитесь, что выполнен шаг прошивки шлюза.
2. Проверьте соединение ESP32 на `115200 бод`.
3. Убедитесь, что передатчик работает на 435.000 МГц с параметрами профиля выше.
4. Раскройте внизу панель **RAW COM**. Если строки там идут, но карточки не обновляются — проблема в формате пакета. Если строк нет — проверяйте радиоканал и ESP32.

## Что нового в 0.8.1

- логотип Альтаира без белой подложки;
- вся верхняя шапка помещается в одну строку;

- рядом с графиками появился список ожидаемых и уже принятых ID;
- RAW COM перенесён вниз и свёрнут по умолчанию;
- сохранены multi-ID графики, точки на линиях, RF-команды, сброс данных и рабочий профиль 435.000 МГц / BW 203 кГц.
