# OpenMCC

**OpenMCC (Open Mission Control Center)** — локальный интерфейс учебного центра управления полётами для CubeSat/МКА. Проект работает офлайн, использует последовательное соединение с микроконтроллерами и постепенно расширяется до полноценной наземной станции с радиоканалом и автоматическим сопровождением спутника.

OpenMCC можно запускать двумя способами:

- как локальный веб-интерфейс в Chrome/Edge;
- как устанавливаемое Windows-приложение `OpenMCC-Setup-<version>.exe`.

## Что уже работает

- подключение Arduino/STM32/ESP32 через Web Serial или desktop-host;
- приём и разбор телеметрии;
- отправка команд;
- журнал событий;
- графики в реальном времени на Chart.js;
- 3D-модель 2U CubeSat на Three.js с рулеточной дипольной антенной;
- отдельный интерфейс двухосевой поворотки AZ/EL;
- симулятор поворотного устройства без реальной механики;
- демонстрационная прошивка Arduino Uno/Nano для телеметрии;
- Windows desktop-host на Electron с нативным выбором последовательного порта;
- автоматическая сборка установщика через GitHub Actions;
- интерфейс выбора CC1101 или E32-433T30D;
- раскрывающиеся таблицы подключения радиомодулей к ESP32-WROOM-32;
- настройка RF-параметров в интерфейсе;
- готовые примеры команд в центре команд;
- прошивка наземного радиошлюза `ESP32-WROOM-32` для CC1101 и E32-433T30D;
- автоматическая CI-сборка готовых бинарных образов прошивки шлюза;
- встроенная прошивка ESP32 прямо из desktop OpenMCC без Arduino IDE;
- определение чипа, прогресс записи и MD5-проверка записанных областей Flash.

## Что пока не реализовано полностью

- аппаратная проверка встроенного прошивальщика на конкретной ESP32-WROOM-32;
- аппаратная проверка прошивки шлюза с реальным CC1101/E32;
- бортовая часть радиоканала на МКА;
- расширенный радиопакет с собственным номером пакета/ACK/повторами поверх возможностей модулей;
- TLE/SGP4;
- карта орбиты и радиогоризонт;
- автоматическое сопровождение спутника;
- проверка реальной механики SatNOGS Rotator v3;
- цифровая подпись Windows-установщика.

## Установка Windows-приложения

После публикации релиза пользователь скачивает файл вида:

```text
OpenMCC-Setup-0.4.0.exe
```

и запускает обычный мастер установки. Python, Node.js, Arduino IDE и отдельный браузер пользователю не требуются.

Подробно: `docs/DESKTOP_APP.md`.

## Прошивка ESP32 прямо из OpenMCC

В desktop-версии v0.4 появился раздел **«Прошивка ESP32»**.

Рабочий процесс:

```text
подключить ESP32-WROOM-32 по USB
        ↓
OpenMCC → Прошивка ESP32
        ↓
Прошить радиошлюз
        ↓
выбрать COM-порт
        ↓
определение ESP32
        ↓
запись bootloader / partitions / boot_app0 / firmware
        ↓
MD5-проверка каждой области
        ↓
перезагрузка
        ↓
Подключить как шлюз
```

Установщик содержит заранее собранную из исходников прошивку. OpenMCC использует официальный `esptool-js` Espressif и Web Serial. Полный `erase-all` по умолчанию не выполняется, поэтому NVS не стирается целиком при обычном обновлении.

Подробно: `docs/FIRMWARE_FLASHER.md`.

## Быстрый запуск веб-версии

### Windows без установки приложения

Запустите:

```text
start_openmcc.bat
```

Скрипт использует Python, если он установлен, либо встроенный PowerShell-сервер.

### Вручную

Из корневой папки проекта:

```bash
py -m http.server 8000
```

Затем откройте в Chrome или Edge:

```text
http://localhost:8000/
```

> Встроенный прошивальщик ESP32 предназначен для desktop-сборки OpenMCC, поскольку именно установщик содержит проверенный комплект бинарных образов.

## Тест телеметрии

Демонстратор:

```text
examples/arduino_avr_demo/OpenMCC_Arduino_AVR/OpenMCC_Arduino_AVR.ino
```

Загрузите его в Arduino Uno/Nano, подключите плату к ПК, выберите в OpenMCC `Arduino Uno` и `115200 бод`, затем нажмите **«Подключить устройство»**.

## Радиоканал

Наземный шлюз реализован на `ESP32-WROOM-32` как отдельный PlatformIO-проект:

```text
firmware/radio_gateway_esp32/
```

Одна прошивка поддерживает альтернативные варианты:

- `CC1101` — SPI;
- `E32-433T30D` — UART.

После выбора OpenMCC показывает рекомендуемое подключение, питание и параметры радиотракта. Кнопка **«Сохранить / передать в шлюз»** формирует `$CMD,RADIO,...`; прошивка ESP32 принимает эту команду, применяет параметры к выбранному модулю и сохраняет их в NVS. Любые остальные `$CMD,...` пересылаются в радиоканал как команды МКА, а принятые `$TEL/$ACK/$ERR/$INFO` возвращаются в OpenMCC.

Подробно:

- `docs/RADIO_CONTROL_UI.md` — интерфейс RF-настроек;
- `firmware/radio_gateway_esp32/README.md` — прошивка, подключение и протокол шлюза.

Статус: код прошивки успешно компилируется в GitHub Actions; физические испытания ожидают появления конкретного радиомодуля.

## Архитектура

```text
                         OpenMCC
                            │
          ┌─────────────────┴─────────────────┐
          │                                   │
      USB / Serial                       USB / Serial
          │                                   │
 ESP32-WROOM-32                        Arduino Uno №2
 радиошлюз ЦУПа                         SatNOGS Rotator v3
          │                                   │
   CC1101 или E32                         CNC Shield V3
          │                                   │
       радиоканал                        NEMA17 AZ / EL
          │
         МКА
```

Пока физический радиостенд не собран, основное USB-соединение по-прежнему можно проверять напрямую с демонстрационной Arduino.

## Сборка Windows-установщика для разработчика

GitHub Actions перед сборкой desktop-приложения автоматически компилирует ESP32 gateway и формирует `bundled_firmware/manifest.json` с контрольными суммами.

Локальная сборка интерфейса без встроенного firmware bundle:

```powershell
npm install
npm run dist:win
```

Для полноценного локального установщика со встроенной прошивкой предварительно нужно собрать ESP32 gateway и подготовить `bundled_firmware` так же, как это делает `.github/workflows/windows-installer.yml`.

## Сборка прошивки ESP32

```bash
pio run -d firmware/radio_gateway_esp32
```

Или используйте артефакт workflow **ESP32 radio gateway firmware** на GitHub.

## Важный принцип проекта

OpenMCC остаётся независимым от конкретного радиомодуля. CC1101 и E32-433T30D скрываются за ESP32-WROOM-32, а интерфейс телеметрии и команд остаётся единым.
