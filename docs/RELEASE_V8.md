# ЦУП Альтаир v8 / 0.8.1

Версия 0.8.1 — доработанная распространяемая сборка ЦУП Альтаир после Технопрома-2026. Основной акцент сделан на первом запуске, удобстве работы оператора и наглядной работе сразу с несколькими спутниками.

## Главное

- рабочий радиопрофиль наземного шлюза сохранён: **435.000 МГц**, 4.8 kbps, 2-FSK, девиация 5 кГц, **RX BW 203 кГц**;
- прикладная XOR-проверка телеметрии отключена, поэтому изменение ID или другого поля без пересчёта XOR не отбрасывает пакет;
- аппаратный CRC CC1101 остаётся включённым;
- прозрачный значок Альтаира используется в интерфейсе и Windows-сборке без белого квадрата;
- шапка стала компактнее: версия, «О программе» и справка находятся в одной строке;
- добавлен обязательный понятный сценарий **1. Прошивка ESP32 → 2. Соединение**;
- если шлюз уже прошит, это можно подтвердить отдельной кнопкой; после успешной прошивки программа запоминает состояние;
- подробная панель соединения сворачивается до компактной строки;
- телеметрия расположена во всю ширину рабочего окна;
- графики идут сразу после телеметрии;
- рядом с графиками добавлена панель состояния ID: `НЕТ СВЯЗИ`, `ПЕРЕДАЁТ`, `БЫЛ НА СВЯЗИ`;
- ожидаемые ID `01…10` видны заранее, дополнительные ID добавляются автоматически;
- цвет ID совпадает с цветом его линий на графиках;
- RAW COM и подробные служебные панели перенесены ниже основного рабочего экрана;
- сохранены RF-команды с ЦУПа, полный сброс данных, несколько цветных линий с точками и окно «О программе»;
- фотографии ЦУПа и CubeSat на главной странице репозитория исправлены.

## ESP32 gateway

Файл ручной прошивки:

`Altair_Gateway_v8.ino`

Радиопрофиль:

```text
435.000 MHz
4.8 kbps
2-FSK
deviation 5 kHz
RX BW 203 kHz
sync 0x12AD
NRZ
variable packet
CC1101 CRC ON
application XOR validation OFF
USB 115200
RF TX ON
```

Базовый пакет:

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM
```

Расширенный пакет:

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,ANTENNA,CHECKSUM
```

Поле `CHECKSUM` сохраняется для совместимости и отображения, но не валидируется на прикладном уровне. Пакет может быть принят даже после изменения ID без пересчёта последних двух HEX-символов.

## Первый запуск

1. Подключить CC1101 к ESP32-WROOM-32.
2. Установить и запустить ЦУП Альтаир.
3. Выполнить шаг **«Прошивка ESP32»** встроенным прошивальщиком или подтвердить, что шлюз уже прошит.
4. После этого выполнить шаг **«Соединение с ЦУПом»** и выбрать COM-порт.
5. Включить спутники-передатчики.
6. Контролировать телеметрию и список ID в верхней части рабочего экрана.

## Несколько спутников

Для ID `01…10` программа заранее показывает состояние связи. После первого пакета ID получает тот же цвет, который используется его линиями на графиках.

- `НЕТ СВЯЗИ` — пакет не принимался в текущей сессии;
- `ПЕРЕДАЁТ` — пакет был принят в последние 5 секунд;
- `БЫЛ НА СВЯЗИ` — хотя бы один пакет ранее принимался, но сейчас поток прекратился.

Другие идентификаторы добавляются автоматически.

## Командный канал

USB-команда ЦУПа шлюзу:

```text
$CMD,RF,TO=02,NAME=PING
```

Пакет в эфире:

```text
$CMD,TO=02,NAME=PING
```

Поддерживаемые команды интерфейса: `PING`, `INFO`, `TM_START`, `TM_STOP`, `TM_PERIOD`, `USER`.

Служебная команда `$CMD,RADIO_STATUS` возвращает фиксированный рабочий профиль наземного шлюза.
