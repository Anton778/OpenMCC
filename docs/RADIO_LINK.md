# План радиоканала OpenMCC

## Назначение

Радиоканал должен быть двусторонним:

```text
МКА → телеметрия → ЦУП
ЦУП → команды → МКА
```

Наземный контроллер: **ESP32-WROOM-32**.

## Вариант CC1101

Предполагаемое подключение:

```text
ESP32-WROOM-32      CC1101
3V3                 VCC
GND                 GND
GPIO18              SCK
GPIO23              MOSI / SI
GPIO19              MISO / SO
GPIO                 CSn
GPIO                 GDO0
GPIO                 GDO2
```

Точные GPIO для `CSn/GDO0/GDO2` выбрать перед написанием прошивки.

Плюсы:

- прямой доступ к пакетному радиотракту;
- RSSI/LQI;
- гибкость формата пакета;
- возможность построить собственный надёжный протокол.

Минус: требуется больше собственной программной логики.

## Вариант E32-433T30D

Предполагаемое подключение:

```text
ESP32-WROOM-32      E32-433T30D
TX2 / GPIO17        RXD
RX2 / GPIO16        TXD
GPIO                 M0
GPIO                 M1
GPIO                 AUX
GND                  GND
```

Для мощной версии предусмотреть отдельное питание подходящей мощности и общую землю.

Плюсы:

- простой UART-интерфейс;
- часть радиопротокола скрыта внутри модуля;
- быстрое прототипирование.

Минус: меньше контроля над физическим и пакетным уровнем.

## Общий протокол OpenMCC

Радиодрайвер должен переносить существующие логические сообщения:

```text
$TEL,...
$CMD,...
$ACK,...
$ERR,...
$INFO,...
```

Для реального радиоканала нужно добавить:

- идентификатор аппарата;
- номер пакета;
- CRC;
- подтверждение критических команд;
- тайм-аут;
- защиту от повторного исполнения команды;
- статистику RSSI/SNR/LQI;
- журнал потерянных пакетов.
