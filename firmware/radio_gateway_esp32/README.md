# ЦУП Альтаир Radio Gateway — ESP32-WROOM-32

Версия прошивки: **0.3.0**  
Версия протокола: **v6**  
Целевая плата: `ESP32-WROOM-32 / esp32dev`  
Сценарий: **Технопром 2026 — Миссия на Луну**

## Назначение

ESP32 соединяет ЦУП Альтаир с наземным CC1101 или E32-433T30D. Основной стенд v6 использует CC1101.

```text
STM32 + CC1101
      │
      │ 435.000 MHz
      ▼
CC1101 + ESP32-WROOM-32
      │ USB, 115200
      ▼
ЦУП Альтаир
```

## CC1101 — подключение к ESP32

| CC1101 | ESP32-WROOM-32 | Назначение |
|---|---|---|
| VCC | 3V3 | питание 3,3 В |
| GND | GND | общая земля |
| SCK | GPIO18 | SPI clock |
| SO/MISO | GPIO19 | CC1101 → ESP32 |
| SI/MOSI | GPIO23 | ESP32 → CC1101 |
| CSn | GPIO21 | Chip Select |
| GDO0 | GPIO4 | событие RX/TX |
| GDO2 | GPIO27 | дополнительный GDO |

## Основной профиль v6

```text
Frequency:     435.000 MHz
Bit rate:      4.8 kbps
Modulation:    2-FSK
Deviation:     5 kHz
RX bandwidth:  58 kHz
TX power:      5 dBm
Preamble:      16 bits
CRC:           enabled
CCA:           enabled
```

Команда настройки из ЦУПа:

```text
$CMD,RADIO,TYPE=CC1101,FREQ=435.000,POWER=5,RATE=4.8,MOD=2FSK,BW=58,CRC=1,CCA=1
```

При первом запуске firmware 0.3.0 используется новая схема конфигурации NVS. Это предотвращает сохранение старой частоты 434 МГц после обновления с v5.

## Пакет телеметрии v6

Основная строка имеет фиксированную длину **29 ASCII-символов**:

```text
02,00001,00015,3.00,4.20,1,33
```

Структура:

```text
ID(2),PACKET(5),UPTIME(5),PANEL_POWER(4),VOLT(4),MODE(1),XOR(2)
```

Контрольная сумма `33` — XOR ASCII-символов строки:

```text
02,00001,00015,3.00,4.20,1,
```

Последняя запятая входит в XOR.

Gateway проверяет:

- общую длину 29;
- длину каждого поля;
- формат `X.XX` для мощности и напряжения;
- `MODE` только 0 или 1;
- два HEX-символа XOR;
- совпадение принятой и рассчитанной XOR-суммы.

При корректном пакете на USB выдаётся:

```text
$TEL,ID=02,PACKET=00001,UPTIME=00015,PANEL_POWER=3.00,VOLT=4.20,MODE=1,CHECKSUM=33,CHECKSUM_OK=1,RSSI=-76.0,SNR=16.0,LQI=103
```

При ошибке XOR:

```text
$ERR,TELEMETRY_XOR,RECV=XX,CALC=YY,RAW=...
```

## RSSI, LQI и SNR

`RSSI` и `LQI` считываются после приёма из CC1101 через RadioLib.

CC1101 не выдаёт отдельное готовое значение SNR пакета, поэтому используется диагностическая оценка:

```text
SNR_est ≈ RSSI_packet - RSSI_noise_floor
```

Её следует калибровать, если требуется метрологически значимое значение.

## E32-433T30D

Альтернативный модуль E32 сохранён для совместимости.

| E32 | ESP32-WROOM-32 |
|---|---|
| TXD | GPIO16 / RX2 |
| RXD | GPIO17 / TX2 |
| M0 | GPIO25 |
| M1 | GPIO26 |
| AUX | GPIO27 |
| GND | GND |

Для режима 30 dBm нужен подходящий отдельный источник питания с общей землёй ESP32.

## Команды шлюза

```text
$CMD,GATEWAY_PING
$CMD,GATEWAY_INFO
$CMD,RADIO_STATUS
$CMD,RADIO,...
```

Прочие `$CMD,...` пересылаются аппарату через выбранный радиомодуль.

## Сборка

```bash
pio run -d firmware/radio_gateway_esp32
```

Зависимость:

```text
jgromes/RadioLib@7.7.1
```

## Прошивка прямо из ЦУП Альтаир

Windows-релиз включает готовые бинарные образы gateway. Через панель **«Прошивка ESP32»** записываются:

```text
0x1000   bootloader
0x8000   partition table
0xE000   boot_app0
0x10000  application
```

После записи выполняется MD5-проверка и перезагрузка ESP32.

## Стендовая проверка

Успешная CI-компиляция подтверждает только программную сборку. До демонстрации необходимо физически проверить STM32 + CC1101 → 435 МГц → CC1101 + ESP32 → ЦУП, а также реальные RSSI/SNR и питание модулей.
