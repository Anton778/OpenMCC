# ЦУП Альтаир v7 / 0.7.0

## Главное исправление

Релиз v7 фиксирует конфигурацию, которая была подтверждена на реальном стенде: STM32 + CC1101 IntroSat передаёт пакет, обычный CC1101 на ESP32 принимает его на 435.000 МГц. При RX bandwidth 58 кГц приём был нестабильным/отсутствовал, а при 203 кГц пакет `02,00001,00015,3.00,4.20,1,33` был успешно декодирован. Поэтому штатная полоса v7 — **203 кГц**.

## Телеметрия

Порядок карточек на экране:

`ID -> PACKET -> UPTIME -> PANEL_POWER -> VOLT -> MODE -> CHECKSUM -> ANTENNA -> RSSI -> SNR`

RSSI и SNR находятся в самом конце, после состояния раскрытия антенны. В минимальном 29-символьном пакете поля антенны пока нет, поэтому интерфейс показывает `Н/Д`, а не прочерк.

## Графики

Графики напряжения, мощности солнечных панелей, RSSI и SNR теперь показывают точку на каждом принятом отсчёте.
