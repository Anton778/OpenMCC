# ЦУП Альтаир

<p align="center">

**ЦУП Альтаир** — учебный центр управления полётами для CubeSat-проектов. Программа принимает телеметрию через наземный радиошлюз ESP32 + CC1101, строит графики для нескольких аппаратов одновременно, показывает состояние связи по ID, позволяет передавать RF-команды и управлять поворотным устройством антенны.

**Актуальная версия: v8 / 0.8.1.**  
Автор: **Антон Т.** Проект создан в рамках образовательной программы **«Миссия на Луну»**, профильной смены по спутникостроению и использовался на Технопроме-2026.

## Быстрый запуск

Интерфейс v8.1 специально построен так, чтобы не перепутать последовательность действий.

1. Подключите CC1101 к ESP32-WROOM-32 по таблице ниже.
2. Запустите **ЦУП Альтаир**.
3. В верхнем блоке **«Подготовка шлюза ЦУП»** выполните **Шаг 1 — Прошивка ESP32**. Если эта ESP32 уже прошивалась актуальной прошивкой, нажмите **«Шлюз уже прошит»**.
4. После завершения первого шага становится доступен **Шаг 2 — Соединение с ЦУПом**.
5. Выберите COM-порт ESP32. Рабочая скорость USB — **115200 бод**.
6. Включите спутники-передатчики. Телеметрия сразу появляется в полноширинном блоке, а ниже строятся графики.

Подробные панели прошивальщика, COM-настроек и RAW COM находятся ниже основного рабочего экрана и могут быть свернуты.

## Рабочий радиопрофиль

| Параметр | Значение |
|---|---:|
| Частота | **435.000 МГц** |
| Модуляция | **2-FSK** |
| Скорость в эфире | **4.8 kbps** |
| Девиация | **5 кГц** |
| Полоса RX | **203 кГц** |
| Sync word | `0x12AD` |
| Encoding | NRZ |
| Длина пакета | variable |
| Аппаратный CRC CC1101 | включён |
| USB ESP32 → ПК | **115200 бод** |

Полоса **203 кГц** выбрана намеренно. На учебных радиомодулях встречается заметный частотный уход, поэтому узкая полоса 58 кГц на реальном стенде приводила к потере пакетов.

## Подключение CC1101 к ESP32

| CC1101 | ESP32-WROOM-32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCK | GPIO18 |
| MISO / SO | GPIO19 |
| MOSI / SI | GPIO23 |
| CSN / CS | GPIO21 |
| GDO0 | GPIO4 |
| GDO2 | GPIO27 |

**CC1101 питается только от 3.3 В.**

## Формат телеметрии

Базовый пакет:

```text
02,00001,00015,3.00,4.20,1,33
```

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,CHECKSUM
```

Расширенный вариант с состоянием раскрытия антенны:

```text
02,00001,00015,3.00,4.20,1,1,33
```

```text
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MODE,ANTENNA,CHECKSUM
```

`ANTENNA=1` — антенна раскрыта, `ANTENNA=0` — сложена. Если поля нет, интерфейс показывает **Н/Д**.

### Контрольная сумма

В v8 поле `CHECKSUM` сохраняется и отображается, но **прикладная XOR-проверка отключена**. Команда может изменить `ID`, напряжение или другое поле и не пересчитывать последние два HEX-символа — пакет всё равно будет принят ЦУПом.

Аппаратный **CRC самого CC1101 остаётся включённым**.

## Несколько спутников одновременно

Графики группируются по `ID`. Каждый впервые принятый ID получает собственный цвет, линию и точки измерений.

Справа от графиков находится список **«Связь по ID»**:

- `НЕТ СВЯЗИ` — пакет от этого ID ещё ни разу не принимался;
- `ПЕРЕДАЁТ` — пакет был получен в последние 5 секунд;
- `БЫЛ НА СВЯЗИ` — аппарат уже принимался, но сейчас пакетов нет.

Для профильной смены заранее отображаются ожидаемые ID `01…10`. Если появляется другой ID, он автоматически добавляется в список. Цвет ID совпадает с цветом его линий на графиках.

Кнопка **«Сбросить принятые данные»** очищает карточки, графики, счётчики, RAW COM и историю принятых ID без перезапуска программы.

## Передача команд с ЦУПа

Наземный CC1101 работает как приёмопередатчик. Например, программа отправляет шлюзу:

```text
$CMD,RF,TO=02,NAME=PING
```

ESP32 передаёт в эфир:

```text
$CMD,TO=02,NAME=PING
```

Штатные команды интерфейса:

| Команда | Назначение |
|---|---|
| `PING` | проверка командного радиоканала |
| `INFO` | запрос информации |
| `TM_START` | запуск телеметрии |
| `TM_STOP` | остановка телеметрии |
| `TM_PERIOD,MS=<N>` | изменение периода передачи |
| `USER,DATA=<текст>` | пользовательская команда |

Бортовая прошивка спутника должна отдельно реализовать реакцию на эти команды. Сам факт передачи с ЦУПа можно проверить SDR-приёмником.

## RAW COM

Панель **RAW COM / DEBUG** показывает строки именно в том виде, в котором они приходят от ESP32, а также команды, отправленные программой. Она специально перемещена ниже телеметрии и графиков, поскольку нужна в основном для диагностики.

Если RAW COM показывает строки быстро, а карточки не обновляются — проверяйте формат пакета. Если строк нет вообще — проверяйте радиоканал, ESP32 и CC1101.

- прозрачный значок Альтаира без белого квадрата;
- `v8 · 0.8.1`, кнопки «О программе» и справки находятся в одной строке шапки;

- исправлены фотографии ЦУПа и CubeSat на главной странице репозитория.

## Разработка

Для локального запуска:

```bash
npm install
npm start
```

Для сборки Windows installer:

```bash
npm run dist:win
```

Репозиторий содержит приложение, прошивки ESP32/STM32, документацию и сборочные workflow. При изменении радиопротокола желательно прикладывать пример принятой строки из RAW COM.
