# STM32 + CC1101 — передатчик ЦУП Альтаир v7

Основной файл для Arduino IDE:

`Transmit_v7_static/Transmit_v7_static.ino`

Он раз в секунду передаёт на 435.000 МГц статический пакет:

`02,00001,00015,3.00,4.20,1,33`

Пакет имеет длину 29 ASCII-символов; XOR `33` рассчитан по строке до контрольной суммы с включением последней запятой.

Рабочие выводы из предыдущего IntroSat-скетча: `CS=PA2`, `GDO0=PA0`, `GDO2=PA1`; SPI — штатные выводы выбранной STM32-платы. Референсная CI-сборка использует `bluepill_f103c8`, но фактическую плату в Arduino IDE нужно выбирать по реальному железу.
