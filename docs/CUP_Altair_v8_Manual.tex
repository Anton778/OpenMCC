\textbf{Назначение.} ЦУП Альтаир — учебный наземный комплекс для приёма телеметрии CubeSat, отображения данных нескольких аппаратов, построения графиков, диагностики последовательного канала и передачи команд через ESP32 + CC1101.

\section{Состав системы}

\begin{center}
\fbox{\parbox{0.93\linewidth}{\centering
\textbf{Спутник + CC1101} $\longrightarrow$ \textbf{435.000 МГц} $\longrightarrow$ \textbf{CC1101 + ESP32} $\longrightarrow$ \textbf{USB 115200} $\longrightarrow$ \textbf{ЦУП Альтаир v8}
}}
\end{center}

На наземной стороне используется широкая полоса приёма \textbf{203 кГц}. Это проверенная стендовая настройка, выбранная из-за заметного частотного ухода части учебных радиомодулей.

\section{Что скачать}

Для обычного пользователя нужны:
\begin{enumerate}[leftmargin=7mm]
\item \code{CUP-Altair-Setup-0.8.1.exe} — Windows-приложение;
\item \code{Altair_Gateway_v8.ino} — прошивка ESP32-WROOM-32 + CC1101, если используется Arduino IDE;
\item настоящий файл \code{CUP_Altair_v8_Manual.pdf} — инструкция.
\end{enumerate}

Прошивка ESP32 также встроена в установщик и может быть записана непосредственно из программы.

Значения в таблице являются исходным профилем. После подключения ESP32 оператор может изменить частоту наземного CC1101 в диапазоне 387--464 МГц, мощность передаваемых команд и полосу приёмника ЦУПа. Кнопка «Сбросить к исходным» возвращает 435.000 МГц, 5 dBm и 203 кГц. Частота применяется к UPLINK и DOWNLINK; мощность относится к передаче команд, а полоса RX --- только к приёму телеметрии.

\section{Телеметрические пакеты}

Базовый пакет:
\begin{lstlisting}
02,00001,00015,1.00,4.20,31.6,1,07
\end{lstlisting}

Поля:
\begin{lstlisting}
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MCU_TEMP,MODE,CHECKSUM
\end{lstlisting}

Поле \code{MCU_TEMP} содержит температуру кристалла бортового микроконтроллера в градусах Цельсия и располагается сразу после напряжения аккумулятора.

Расширенный вариант с состоянием антенны:
\begin{lstlisting}
02,00001,00015,1.00,4.20,31.6,1,1,07
\end{lstlisting}

Поля:
\begin{lstlisting}
ID,PACKET,UPTIME,PANEL_POWER,VOLT,MCU_TEMP,MODE,ANTENNA,CHECKSUM
\end{lstlisting}

\code{ANTENNA=1} означает раскрытую антенну, \code{ANTENNA=0} — сложенную. При отсутствии поля ЦУП показывает \textbf{Н/Д}.

\subsection{Контрольная сумма}

В v8 последние два символа \code{CHECKSUM} сохраняются и отображаются, однако \textbf{прикладная XOR-проверка отключена}. Поэтому изменение ID или другого поля без пересчёта XOR не приводит к отбрасыванию всего пакета.

Это не отключает аппаратный CRC пакетного механизма CC1101: пакеты, которые радиочип определил как повреждённые по CRC, по-прежнему отмечаются как ошибка радиоприёма.

\section{Первый запуск}

\begin{enumerate}[leftmargin=7mm]
\item Подключить ESP32 + CC1101 по таблице выше.
\item Прошить ESP32 файлом \code{Altair_Gateway_v8.ino} либо встроенным прошивальщиком ЦУПа.
\item Подключить ESP32 к компьютеру USB-кабелем.
\item Если открыт Serial Monitor Arduino IDE — закрыть его.
\item Запустить ЦУП Альтаир.
\item В панели соединения выбрать ESP32 и 115200 бод.
\item Нажать «Подключить устройство» и выбрать COM-порт.
\item После успешного подключения панель автоматически сворачивается; при необходимости её можно раскрыть.
\end{enumerate}

На главном экране отдельно показаны UPLINK и DOWNLINK. При исходной конфигурации для обоих направлений отображаются 435.000 МГц и полоса 203 кГц.

\section{Несколько спутников}

Каждая телеметрическая строка содержит ID аппарата. Графики v8 автоматически создают отдельный набор данных для каждого ID. Например, если одновременно принимаются аппараты 01, 02 и 07, на одном графике будут три разные линии и три цвета. Рядом с графиками накапливается список всех обнаруженных ID и число принятых пакетов каждого аппарата.

Кнопка \textbf{«Сбросить принятые данные»} очищает карточки, графики, счётчики и сырой COM-журнал без перезапуска программы.

\section{Сырой COM-терминал}

Панель \textbf{RAW COM / DEBUG} показывает полные строки, поступающие от ESP32, а также строки, переданные программой в последовательный порт.

Она нужна для ответа на простой диагностический вопрос: действительно ли данные поступают редко или они быстро приходят по USB, но не распознаются парсером. ЦУП не вводит специальную задержку между приёмом строки и её отображением.

Если строки отсутствуют в RAW COM, проверяется радиотракт и ESP32. Если строки есть, но карточки не обновляются, проверяется формат телеметрии.

\section{Передача команд}

ЦУП v8 может передавать команды через тот же наземный CC1101.

Команда программы для ESP32:
\begin{lstlisting}
$CMD,RF,TO=02,NAME=PING
\end{lstlisting}

ESP32 удаляет служебное поле \code{RF} и передаёт в эфир:
\begin{lstlisting}
$CMD,TO=02,NAME=PING
\end{lstlisting}

\begin{center}
\begin{tabularx}{\linewidth}{lX}
\toprule
Команда & Назначение\\
\midrule
PING & проверка командного радиоканала\\
INFO & запрос информации от бортовой программы\\
TM\_START & запуск телеметрии\\
TM\_STOP & остановка телеметрии\\
TM\_PERIOD,MS=N & изменение периода передачи\\
USER,DATA=text & пользовательская команда\\
\bottomrule
\end{tabularx}
\end{center}

Адрес \code{ALL} предназначен для широковещательной команды. Реакцию на команду должна реализовать бортовая прошивка конкретного спутника. Даже без бортового обработчика сам факт передачи можно проверить SDR-приёмником.

Служебная команда \code{$CMD,RADIO_STATUS} возвращает текущий профиль шлюза. Для изменения параметров используется:
\begin{lstlisting}
$CMD,RADIO,SET,FREQ=435.000,POWER=5,BW=203
\end{lstlisting}
Для возврата исходных значений используется \code{$CMD,RADIO,RESET}.

\section{Индикация и ошибки}

ЦУП разделяет ошибки прикладного формата и ошибки радиоканала. Прикладная XOR-проверка не используется. Сообщение \code{$ERR,RADIO_RX_CRC} означает, что аппаратный CRC CC1101 не прошёл. Нераспознанная, но физически принятая строка остаётся доступна в RAW COM для диагностики.
