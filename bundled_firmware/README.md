# Встроенная прошивка ESP32

Эта папка заполняется автоматически при сборке настольной версии ЦУП Альтаир.

GitHub Actions компилирует проект [`firmware/ground_station/esp32`](../firmware/ground_station/esp32), затем копирует в эту папку четыре образа для ESP32-WROOM-32:

- загрузчик — адрес `0x1000`;
- таблица разделов — адрес `0x8000`;
- `boot_app0` — адрес `0xE000`;
- приложение радиошлюза ЦУП Альтаир — адрес `0x10000`.

Также генерируется `manifest.json` с версией прошивки, размерами и контрольными суммами MD5. Этот комплект включается в Windows-установщик и используется разделом **«Прошивка ESP32»**.

Бинарные файлы намеренно не хранятся вручную в Git: они создаются из актуального скетча в CI, чтобы исходный код и встроенная прошивка не расходились.
